# Olist E-Commerce Sales & Customer Analysis Dashboard

This project analyzes e-commerce sales data using SQL and visualizes insights using Power BI.

## Objective
To analyze sales trends, customer behavior, product performance, and order status using SQL and Power BI.

## Tools Used
- PostgreSQL (SQL queries)
- Power BI (Dashboard visualization)
- Excel (Data handling)

## Dataset
The dataset contains three main tables:
- Customers data
- Orders data
- Order items data

## Process

- Imported data into PostgreSQL  
- Cleaned and transformed data  
- Fixed timestamp data type issue  
- Created SQL queries for analysis  
- Exported results to CSV files  
- Built Power BI dashboard  

## SQL Analysis Performed

- Monthly sales trend  
- Monthly order count  
- Average order value  
- Top 10 customers  
- Top products  
- Order status distribution  

## Key Insights

- Sales show a steady monthly growth trend  
- Top customers contribute majority of revenue  
- Few products generate most of the sales  
- Most orders are successfully delivered  
- Order cancellations are low  

## Dashboard Features

- KPI Cards (Sales, Orders, Avg Order Value)  
- Monthly Sales Trend (Line Chart)  
- Top Customers (Bar Chart)  
- Top Products (Bar Chart)  
- Order Status (Pie Chart)  

## Conclusion
This project helps in understanding business performance and supports data-driven decision making.
